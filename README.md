## 주요 기능
### 1. 데이터-세이브 시스템 플로우

담당자: 주혁
- 데이터 / 데이터베이스
- 세이브 데이터
- 저장 담당 매니저(임시 저장, 백업 생성, 최종 교체)
- 플레이어 정보 Sciptable Object

### 2. 플레이어 스탯 플로우

담당자: 주혁
- 베이스 스탯 + 장비 장착 스탯 / 비전투 시 스탯 관리
- 패시브, 무기 능력 / 각 관리 매니저
- 전체 스탯 통합 관리

### 3. 전투 플로우

담당자: 오준희
- 플레이어 컨트롤
- 몬스터 행동 패턴
- 전투 상호작용(UI, 스폰, 공격 및 피격)
- 드롭 아이템

### 4. 비전투(정비) 시스템

담당자: 윤성원
- 전투 스테이지 이동
- 장비 획득 및 장착
- 가챠 시스템
- 진화(스탯 업그레이드) 시스템

### 5. 애니메이션, FX

담당자: 임재석
- DoTween 활용 FX 효과
- 플레이어, 적 애니메이션 클립
